# Simple Trace Example

Demonstrates basic usage of @ocpp-debugkit/toolkit: parse a trace, detect
failures, and generate a Markdown report.

## Run

```bash
npm install
npm start
```

## What it does

1. Parses a synthetic OCPP trace file
2. Builds session timeline
3. Detects failures
4. Prints a summary to stdout
5. Generates a Markdown report
